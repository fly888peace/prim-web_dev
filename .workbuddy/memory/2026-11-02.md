## web_dev：ES 模块化 + 动画/排版改造

- 起因：用户参照 `/home/zero-to-tech-demos/zero-to-tech-4-1`（模块 4.1 模块化配套代码），要求把自己的游戏记录站也改成 `css/` + `js/` 两文件夹的 ES 模块结构，并加动画和排版特效。
- 样式：`style.css` 拆成 `css/` 9 个文件——variables / reset / layout / hero / list / post / footer / effects / responsive；变量文件放最前、responsive 放最后。
- 脚本：`js/` 6 个 ES 模块——`main.js` 入口、`motion.js` 动画底座（anime.js 4.x 用 CDN `+esm`）、`hero.js` 标题拆字、`list.js` 列表错峰入场、`post.js` 正文逐段浮现 + 阅读进度条、`year.js` 页脚年份；页面只留一行 `<script type="module">`。
- 降级设计：只有 `<html class="motion">` 时 CSS 才隐藏待入场元素，`main.js` 在加载动画模块前加类、失败/`prefers-reduced-motion` 时移除，保证 CDN 挂掉或双击 `file://` 打开不白屏。
- 排版特效：首字下沉、标题墨线展开、记录标题悬停下划线、缩略图轻微放大、阅读进度条。
- 踩坑：对同一文件并行发两次 `replace_in_file` 会互相覆盖（posts 的 `.reading-progress` div 被吞了一次），同文件编辑必须串行。
- 验证限制：环境里没有浏览器（node/chromium 均无），只验证了资源 200 + MIME 正确 + 链接存在，动画效果未做截图确认。
