## web_dev：游戏记录静态站（初版）

- 用户目的澄清：**不是**小游戏集合，是「游戏游玩记录」——自己的截图 + 文字攻略。第一次我擅自加了示例小游戏，被告知可以加东西，但加什么要先问。
- 交付结构（纯静态、无构建、无依赖）：
  - `index.html` 记录列表（缩略图 + 游戏名/日期 + 标题 + 两行摘要）
  - `posts/sample-01.html`、`posts/sample-02.html` 详情页模板（封面图 / h2 分节 / figure+figcaption / 引用块）
  - `style.css` 单文件，首页与详情页共用；米白纸感底 + 宋体标题、无衬线正文
  - `assets/images/cover-01.svg`、`cover-02.svg` 占位图，待换真实截图
  - `README.md` 部署说明（nginx / python http.server / git pull 更新）与新增记录步骤
- 验证方式：本地 `python -m http.server` + Chrome headless 截图，修复了首页缩略图下方露浅色底条的问题（`.entry__thumb` 加 `aspect-ratio:16/9` + `align-self:center`，img 改 `height:100%`）。
