## web_dev：从 vanilla 多页改造成 React 单页（模块 4.3）

- 用户授权原话：「可以你干吧，改我的项目，变成react管理」。
- 改造前状态：`index.html` + `posts/*.html` 两个独立页面（4.2 结构），`css/` 9 个文件、`js/` 6 个 ES 模块、`src/result.js` 是 4.3 第一拍的中间态。
- 改造后结构：
  - `index.html` 退化为 12 行空壳（`#root` + `/src/main.jsx`）
  - `src/main.jsx` 引 9 个 CSS + `createRoot` 挂 `App`
  - `src/App.jsx` 用 `useState(activeId)` 决定首页/详情；额外接了 `location.hash` 路由（课程 4.3 之外，为保留分享链接与刷新）
  - `src/data/posts.js`：两篇记录的内容全部变成 JS 对象，正文用 `blocks` 数组（p/h2/ul/ol/quote/figure/hr）
  - `src/components/`：SiteHero / PostList / PostEntry / PostDetail / PostBody / Footer
  - `src/lib/motion.js`：anime.js 封装改成「传元素进来」，reveal* 返回 cleanup
  - 图片迁到 `public/images/`（引用 `/images/xxx.svg`）
  - 删除：`js/`、旧 `css/`、`posts/`、`dist/`、`src/result.js`、`assets/`
- 关键坑（已写进代码注释）：StrictMode 下 effect「执行→清理→再执行」，若用 `dataset.played` 守卫导致第二次直接 return，第一次的 IntersectionObserver 已被 cleanup 断开，列表会永远停在 `opacity:0`（整块空白）。实测首页确实白过一次，去掉守卫后正常。
- 另一处：`package.json` 补 `"type": "module"`，消除 vite.config.js 被当 CJS 加载的警告。
- 验证（真实证据）：`npm run build` 通过（82 modules，CSS 7.47kB 合并为一份）；headless Chrome + CDP 实测：390 宽视口 `scrollWidth=390` 无横向溢出；点击 `.entry` → hash `#sample-01`、`.post__title` 正确、正文 12 个直接子元素；点返回 → hash `""`、回到首页 true；dist 静态服务渲染与 dev 完全一致。
- 遗留：`src/components/ResultCard.jsx`（第一拍练习）无任何引用，未删，已告知用户。
